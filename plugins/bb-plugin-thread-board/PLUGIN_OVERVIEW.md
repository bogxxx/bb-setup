Threads from every project, in three columns under the message box.

## Columns

**needs you**, **done**, and **running**, in that order. Needs you is a question, a failed send, a failure, or an unread thread. Running is a busy thread, a queued message, a plan, a workflow, or background work. Done is what finished within the last few days, and anything pinned stays past that.

Cards are grouped by project. The project you are composing in comes first. Each header is the project's first letter in a small tile, then its name.

## Snoozed, not archived

Snoozed threads stay on the board. A question or a failed send always counts. An unread or failed snoozed thread counts only while it was touched inside the done window; older ones drop off. A snoozed thread that is still working stays in running. One that has finished inside the window sits in done with a muted **snoozed** chip. Archived threads are not listed.

## Children and review

A child thread gets its own card only when it asks something or a send to it failed. Any other child, including a snoozed one, counts toward the top-level thread instead. That thread stays in running while a descendant is busy.

A child titled `review` that needs you is marked **review**. A running card that would have said **agents** says **review** when a busy descendant is a reviewer. A top-level thread titled review is not treated as a reviewer. Pinned done cards say **pinned**. A plain done card has no chip.

## Hover, settings, sidebar

Hovering a card shows its title, chip, and up to five recent steps, split between the agent and you. `showBoard` turns the section off. `doneDays` sets the window for finished threads and for a stale snoozed unread.

The same time, project badge, and chip can sit on a thread row's metadata line under the title, and only after Organize → Rows → Metadata is on.
